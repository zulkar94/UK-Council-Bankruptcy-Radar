# Data sources

All sources are public. Raw downloads go in `data/raw/`, which git ignores. Only column maps and the small reference file are committed.

## Finance

| Data | Publisher | Link | Notes |
|---|---|---|---|
| Revenue outturn, multi-year (2017-18 to 2024-25) | MHCLG | https://www.gov.uk/government/statistics/local-authority-revenue-expenditure-and-financing-england-revenue-outturn-multi-year-data-set | Main source for net expenditure, reserves and service spend. Check units in the metadata (expected £ thousands). |
| Revenue outturn, individual authority data by year | MHCLG | https://gov.uk/government/collections/local-authority-revenue-expenditure-and-financing | Use for 2025-26, which isn't in the multi-year set yet. |
| Capital expenditure and receipts, individual authority data | MHCLG | https://www.gov.uk/government/statistics/local-authority-capital-expenditure-and-receipts-in-england-2024-to-2025-individual-local-authority-data | For borrowing and commercial investment signals. |
| Core spending power | MHCLG | Published with each local government finance settlement | Denominator for debt and commercial exposure. |
| Council names and codes | ONS Open Geography Portal | geoportal.statistics.gov.uk | Local Authority Districts plus Counties lists. |

Column headers for MHCLG files are **not** hard-coded. Run `council-radar inspect <file>` and fill in a copy of `ro_multi_year_TEMPLATE.toml`.

### Exceptional Financial Support (104 rows)

- 2025-26 round, decisions published 20 February 2025: https://www.gov.uk/guidance/exceptional-financial-support-for-local-authorities-for-2025-26
- 2026-27 round, decisions published 23 February 2026: https://www.gov.uk/guidance/exceptional-financial-support-for-local-authorities-for-2026-27

`financial_year` is the year the support covers, as an ending year (2026 means 2025-26). Amounts are £m as published, using revised figures where the page gives them.

**Included:** general fund support for councils.

**Excluded:** Housing Revenue Account rows (City of London, Lambeth's HRA entry), police bodies and combined authorities.

These rows were transcribed from the gov.uk pages with an automated fetch on 26 November 2026. Spot-check them against the source before publishing any results.

**Still to add:** the 2024-25 and earlier EFS rounds (the scheme has run since 2020).
